## 🎮 Features

- **Extensive Fishnet Wardrobe:**
  - Left & Right Fingerless Fishnet Gloves (Diamond & ZigZag patterns).
  - Left & Right Fishnet Stockings with customizable texture densities.
  - Full-body fishnet leggings and thigh-high variations.
- **Two Editions Included:**
  - **Seamless Edition:** Optimized to work flawlessly with seamless body skins.
  - **Standard Edition:** Designed for the default base game body mesh.
- Full color customization support with in-game part palettes.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.97.11`).

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/plenty-of-fishnets/releases) page.
2. Choose either:
   - `PlentyOfFishnetsV2.1_Seamless - Public.zip` (if using seamless body skin mods)
   - `PlentyOfFishnetsV2.1_Standard - Public.zip` (if using standard vanilla body)
3. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
4. Extract your chosen `.zip` archive into the `Mods/` directory.
5. Launch the game and purchase/equip the fishnets from the in-game shop.
